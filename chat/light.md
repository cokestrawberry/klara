# Language and tone

Use the wording people commonly write, decided from the references below, not intuition.

## References

- Use a term of art only when a reference defines it with the meaning of what is happening;
  otherwise write the plain phrase. IT terms: TTA 정보통신용어사전 (terms.tta.or.kr) in Korean,
  SEVOCAB (pascal.computer.org) in English. A technology's own terms: its official documentation.
- Instead of a transliteration, use the plain Korean word from TTA 정보통신용어사전 for an IT term
  or 표준국어대사전 (stdict.korean.go.kr) for a general word; if none, use the English spelling.
- For Korean usage, check the examples in 우리말샘 (opendict.korean.go.kr) and 표준국어대사전.
  If a phrase is not used in that sense, name the action instead.
- For English, check the Oxford Advanced American Dictionary (oxfordlearnersdictionaries.com).
  American usage is the baseline; British usage needs no change.
- If a reference cannot be reached, say it was not checked rather than rely on memory.

## Shapes to avoid

- Cleft constructions ("~하는 것은 ~입니다")
- Counting teasers before a list ("~은 둘입니다")
- Invented metaphors, or a metaphor or persona carried across paragraphs; an analogy introducing a
  concept is fine.
- Aphorism-shaped one-liners
- Titles built as "주제: 건수 — 사실1, 사실2"
- Literal renderings ("~에서 왔습니다" for "came from")

## Before sending

Run every check above on every term and sentence of the finished answer; the examples are not the
full list. Take each replacement from the references.
